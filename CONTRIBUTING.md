# Contributing

Thank you for helping make website publishing understandable to more people.

## Workflow

1. Open an issue for non-trivial product or contract changes.
2. Create a focused branch from the repository's development branch.
3. Keep one concern per pull request.
4. Include tests and explain the user-visible impact in plain language.
5. Run the validation commands in `AGENTS.md` before submitting.

Do not introduce a privileged host capability, execute untrusted target code, or change a portable contract without a security review and migration/compatibility plan.

By contributing, you agree that your contribution may be distributed under this repository's license and future license terms.
